# Instructions for AI assistants

Before doing anything in this repository, read these files in order:

1. `CODE-SOURCING-RULES.md`: **Do not generate any new code.** Only copy code directly from public GitHub UI/UX repos with a reuse license, and log every source in `SOURCES.md` in the same commit.
2. `CONTEXT.md`: project background and how the NHD WebCentral editor behaves (hex colors only, no Bootstrap class names, everything scoped under `#fm`).
3. `DESIGN.md`: the "1901 Apothecary Broadsheet" style every change must follow.
4. `HOW-TO-PASTE.md`: how the user gets the code into the editor. Explain changes in plain language; the user doesn't write code.

Never write the page's text content. Use bracketed placeholders such as `[Text]`. Never use em dashes or en dashes in anything you write for this user.
