# Project Context

Background for anyone, person or AI, picking up this project. Read together with `CODE-SOURCING-RULES.md` (where code may come from) and `DESIGN.md` (how it must look).

## The project

- **Contest:** National History Day (NHD), Website category.
- **Title:** "A Fatal Mix-Up: The 1901 Diphtheria Tragedy and America's First Leap into Drug Regulation."
- **Platform:** NHD WebCentral. Edit at site.nhdwebcentral.org; the live home page is https://site.nhdwebcentral.org/90886777/home
- **Pages on the site:** Home, Thesis (`thesis_4`), Background, Bibliography. The nav bar is generated by the editor from the `[***smart-nav***]` tag.
- **The builder doesn't write code by hand.** They copy and paste code into the editor, so every change must work on the first paste.

## NHD contest rules that matter here

From the NHD website rule summary:
- The site must be built in NHD WebCentral by the student ("Another person may show you how to use the editor, but you must build yourself").
- The student must be the sole author. Reasonable help from others is allowed.
- **Everything taken from others must be credited.** Not crediting it counts as plagiarism. This is why `SOURCES.md` exists: credit every library and component in the annotated bibliography.
- Code doesn't count toward the word limit.
- Check the current NHD Rule Book and ask the teacher or contest coordinator about outside code and AI use.

## How the NHD editor works

- It's built on **GrapesJS** (drag and drop) and loads **Bootstrap 4.3.1**, jQuery and Font Awesome on every page.
- The **Import** window (the tray-with-down-arrow button in the top toolbar) has an **HTML** box and a **CSS** box. Pasting replaces the whole page. See `HOW-TO-PASTE.md`.
- Each page is wrapped in `<div class="container it-is-set">`, which Bootstrap caps at 1140px wide.
- **Scripts:** `<script>` tags pasted into the HTML box are kept and **run on the published site and in Preview**. The site's security settings allow inline scripts (`script-src 'unsafe-inline'`). Scripts do **not** run inside the editor canvas.
- **External files are blocked.** The page may only load images from its own site (`img-src 'self'`) and scripts or styles from a short list of approved hosts. Keep everything inline in `home.html` and `home.css`, and upload images through **Manage Files**.
- Clicking in the editor canvas selects elements; use **Preview** (eye icon) to test clicks and hovers.

## Lessons learned on the live site (2026-10-25)

1. **Color variables turn black.** On import, the editor rewrote every `color:var(--x)` and `background-color:var(--x)` as `#000000`. Always write colors as hex codes.
2. **Bootstrap class names clash.** Never use `container`, `card`, `row`, `col`, `btn`, `nav`, `navbar`, `badge`, `alert`, `modal`, `carousel-item`, `active`, `collapse`, `jumbotron` for your own elements.
3. **Full width needs an override:** `.container.it-is-set{max-width:100%; padding-left:0; padding-right:0;}` (first rule in `home.css`).
4. **Bootstrap margins:** reset margins on `p`, `label`, `figure`, `h1` to `h3` inside `#fm` where spacing matters.
5. **Old scripts linger.** The old slideshow script kept running after the first redesign and added `.carousel-nav` dots. Replacing all the HTML in the Import window removes it; `#fm .carousel-nav{display:none}` hides any leftover.
6. **A `<style>` block from a library can break on import.** `sal.css` was not pasted; plain state classes in `home.css` do the same job.
7. **Only one person should edit at a time.** The editor shows "X is currently editing this page"; two people editing at once can overwrite each other.

## Page structure (home.html)

Everything sits inside `<div id="fm">`. Every CSS rule starts with `#fm` so nothing leaks into the rest of the site.

| Section | Class / id | Contents |
|---|---|---|
| Hero | `.hero` | Masthead (`.mast`: `#itsa` title, `#i2k2s` subtitle) and the slideshow (`#isl1`: 4 slides, 1 to 4 picker, captions). Fills the first screen. |
| Opening | `.opening` | `#ihq6k` intro paragraph with drop cap; `#ipwhb` "13 Children died" box (counts up). |
| Hover cards | `.reveal` | 4 cards: `[Heading]` slides away to show `[Text]`. |
| Feature | `.feature` | Image with caption, plus a heading, text and a hover definition (`.tip`). |
| Flip cards | `.flips` | 3 cards: image front, `[Text]` back. |
| Quote | `.notes` | `[Quote]` and `[Source]` on ruled paper. |
| Closing | `.closing` | Click-to-open `details` and the Thesis button `#irtjk` linking to `thesis_4`. |
| Scripts | bottom of `home.html` | vanilla-tilt.js, sal.js, countUp.js (unchanged) and the setup script. |
