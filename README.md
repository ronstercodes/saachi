# A Fatal Mix-Up: NHD Website

Code for the home page of the National History Day website **"A Fatal Mix-Up: The 1901 Diphtheria Tragedy and America's First Leap into Drug Regulation,"** built in NHD WebCentral (site.nhdwebcentral.org).

Live page: https://site.nhdwebcentral.org/90886777/home

## What's in this repo

| File | What it is |
|---|---|
| `home.html` | The page markup, including the effect scripts at the bottom. Goes into the **HTML** box of the editor's Import window. |
| `home.css` | All the page styles. Goes into the **CSS** box of the Import window. |
| `HOW-TO-PASTE.md` | Step by step: how to get this code into the NHD editor. **Start here.** |
| `CODE-SOURCING-RULES.md` | The rule for all future changes: no newly written code; only code copied from public GitHub UI/UX repos, and every source logged. |
| `SOURCES.md` | The log of every piece of outside code used, with the exact repo, file, author, commit and license. |
| `DESIGN.md` | The style guide ("1901 Apothecary Broadsheet"): colors, type, shapes, motion, components. |
| `CONTEXT.md` | Background on the project, how NHD WebCentral behaves, and what has already been learned the hard way. |
| `THIRD_PARTY_NOTICES.md` | The MIT license texts for every outside library and component. |
| `original-export/` | The page as it was before the redesign (the starting point). |
| `docs/` | The NHD editor instructions file and screenshots of the editor. |

## Quick start

1. Open `home.html`, copy everything.
2. Open `home.css`, copy everything.
3. In the NHD editor, click the **Import** button (tray with a down arrow) in the top toolbar and paste each into its box.
4. Click **Save**, then **Preview** (eye icon) to see the effects.

Full instructions with screenshots are in `HOW-TO-PASTE.md`.
